# jipwatch

서울 아파트 매수를 앞두고 관심 단지를 몇 달씩 지켜보기 위한 데스크톱 앱이에요.
국토교통부 실거래가 공개 API에서 거래를 받아 이 PC에 쌓고, 가격 흐름과 구 대비 수준,
매수와 전세의 손익분기를 보여줘요.

서버 없이 내 PC에서만 돌아요. API 키와 입력한 현금·금리 같은 값은 이 PC의 SQLite 파일에만 저장돼요.

> 투자 조언이 아니에요. 세금과 비용은 어림값이니, 큰 결정 전에는 꼭 따로 확인하세요.

## 기능

- **관심 단지 동기화**: 단지를 관심 목록에 넣으면 그 구의 2016년 1월 이후 거래를 받아와요.
  앱을 열 때마다 최근 3개월을 다시 받아서 늦게 신고된 거래와 해제된 거래를 반영해요.
- **정상 거래만 분석**: 해제된 거래, 직거래, 1~2층 거래는 표에는 보여주되 가격 분석에서는 빼요.
- **가격 흐름**: 평형별 거래 점도표와 추세선(앞뒤 3개월 중간값)을 그려요.
  거래가 드문 구간은 앞뒤 최대 6개월까지 넓혀 보고 점선으로 표시해요.
  하락 전 고점, 하락기 바닥, 최근 6개월 중간값도 보여줘요.
- **구 대비 프리미엄**: 같은 구, 비슷한 면적(±5㎡)의 다른 단지 거래와 비교해서
  이 단지가 평소보다 비싸게 거래되는지 싸게 거래되는지 보여줘요.
- **매수 vs 전세**: 같은 현금으로 사는 것과 전세 사는 것의 1년 비용을 비교해서,
  집값이 연 몇 % 올라야 사는 쪽이 이득인지 계산해요.
  기회수익률을 3%, 5%, 7%로 바꿨을 때의 결과도 같이 보여줘요.
- **월별 거래 찾기**: 구와 계약 월로 그 달의 거래를 단지별로 볼 수 있어요.

## 준비

- Go 1.26 이상
- Node.js (npm)
- [Wails v2 CLI](https://wails.io/docs/gettingstarted/installation)
  ```bash
  go install github.com/wailsapp/wails/v2/cmd/wails@latest
  wails doctor
  ```
- 공공데이터포털 API 키
  1. [data.go.kr](https://www.data.go.kr)에 가입해요.
  2. **국토교통부_아파트 매매 실거래가 상세 자료**(데이터 번호 15126468)를 활용 신청해요.
     이름이 비슷한 토지나 단독주택 API와 헷갈리지 않게 조심하세요.
  3. 마이페이지에서 인증키를 복사해요. Encoding 키와 Decoding 키 중 어느 것이든 돼요.
  4. 신청 직후에는 키가 등록되지 않았다는 오류(코드 30)가 날 수 있어요.
     보통 한두 시간 안에 풀려요.

## 실행

```bash
wails dev      # 개발 모드
wails build    # build/bin/에 실행 파일을 만들어요
```

처음 실행하면 API 키를 물어봐요. 키는 저장하기 전에 실제 요청을 한 번 보내서 확인해요.

## 데이터

| 항목 | 위치 |
|---|---|
| Windows | `%AppData%\jipwatch\jipwatch.db` |
| macOS | `~/Library/Application Support/jipwatch/jipwatch.db` |
| Linux | `~/.config/jipwatch/jipwatch.db` |

이 파일 하나에 API 키, 받은 거래, 관심 단지, 입력값이 모두 들어 있어요.
지우면 처음 상태로 돌아가요.

실거래 신고 기한이 계약 후 30일이라, 최근 한두 달의 거래는 앞으로 더 늘어날 수 있어요.

## 분석 방식

- **평형**: 전용면적의 정수 부분으로 묶어요. 예를 들어 84.97㎡는 84㎡로 봐요.
- **추세선**: 달마다 앞뒤 3개월 정상 거래의 중간값이에요.
  거래가 3건보다 적으면 한 달씩 넓혀서 최대 6개월까지 봐요.
- **고점과 바닥**: 추세선에서 가장 크게 떨어진 구간의 시작점과 끝점이에요.
- **구 대비 프리미엄**: 달마다 (이 단지 중간값 ÷ 구의 같은 면적대 중간값 − 1)을 구해요.
  평소 수준과 표준편차를 구해서, 1 표준편차를 넘으면 평소보다 비싸거나 싸다고 판단해요.
  구 평균에는 신축과 구축이 섞여 있으니 숫자 자체보다 이 단지의 평소 수준과 비교해서 보세요.
- **매수 vs 전세**
  - 살 때 드는 비용: 대출 이자, 집에 묶인 현금의 기회비용, 보유세, 유지보수,
    (취득세 + 중개수수료) ÷ 보유 기간
  - 전세 살 때 드는 비용: 보증금에 묶인 현금의 기회비용, 현금이 모자랄 때의 전세대출 이자,
    중개수수료 ÷ 2년
  - 손익분기 상승률 = (살 때 비용 − 전세 비용) ÷ 매매가
  - 1주택 기준이에요. 취득세는 2025년 요율, 중개수수료는 법정 상한으로 계산해요.
    보유세는 공시가를 매매가의 70%로 보고 특례 없이 어림해요.

## 구조

```
main.go, app.go        Wails 진입점과 프런트엔드에 공개하는 메서드
sync.go                관심 단지가 있는 구의 거래 동기화
analysis.go, trend.go  정상 거래 필터, 추세선, 고점과 바닥
relative.go            구 대비 프리미엄
buyrent.go             매수 vs 전세 손익분기
internal/molit         실거래가 API 클라이언트와 응답 파서
internal/store         SQLite 저장소 (modernc.org/sqlite, cgo 없음)
frontend/              Vite + 바닐라 JS + Chart.js
```
